## Featured Project

### MLB Whiff Prediction — 2026

**Research Question:**
Among MLB pitches that batters swing at, can pitch characteristics and game context predict whether the swing will result in a whiff?

I used **271,362 MLB swings** from the 2026 season through September 2 using Statcast data from Baseball Savant to build machine learning models that predict whether a swing will result in a whiff. The project compares a baseline model, Logistic Regression, and Random Forest using pitch characteristics and game context.

**Key Finding:**
The Random Forest model achieved **81.19% accuracy** and a **0.7745 ROC-AUC**, identifying substantially more actual whiffs than the baseline and Logistic Regression models.

**Tools:** Python · Pandas · Scikit-learn · Machine Learning · MLB Statcast
