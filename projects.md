## Project 2: MLB Whiff Prediction — 2026

**Research Question:** Among MLB pitches that batters swing at, can pitch characteristics and game context predict whether the swing will result in a whiff?

I used **271,362 MLB swings** from the 2026 season using Statcast data from Baseball Savant to build machine learning models that predict whether a swing will result in a whiff. The project compares a baseline model, Logistic Regression, and Random Forest using pitch characteristics and game context.

**Key Finding:** The Random Forest model achieved **81.19% accuracy** and a **0.7745 ROC-AUC**, identifying more actual whiffs than the baseline and Logistic Regression models.

**Tools:** Python · Pandas · Scikit-learn · Machine Learning · MLB Statcast

## Project 1: MLB Pitch Effectiveness — 2026

**Research Question:** Which MLB pitch types are most effective at limiting offensive production during the 2026 MLB season?

I analyzed **559,722 MLB pitches** from the 2026 season using Statcast data from Baseball Savant. The project compares eight major pitch types using run value, whiff rate, wOBA, expected batting average, exit velocity, and hard-hit rate.

**Key Finding:** Changeups had the highest average Effectiveness Score at **0.713**, while sinkers ranked lowest at **-0.525**.

**Tools:** Python · Pandas · Matplotlib · Baseball Savant
